# 盆底压力与肌肉信号上位机

## 运行

在项目目录执行：

```bash
npm start
```

也可以直接双击项目根目录下的：

```text
启动上位机.bat
```

启动脚本会打开一个独立终端并自动打开传感器页面。需要强制停止时，
可以双击：

```text
停止上位机.bat
```

也可以在启动终端中按 `Ctrl+C`。

该命令会同时启动：

- Vite 前端：<http://localhost:5173>
- WebSocket 串口服务：`ws://127.0.0.1:8080`

浏览器打开：

```text
http://localhost:5173/sensor
```

盆底肌模型培训页面：

```text
http://localhost:5173/training
```

按 `Ctrl+C` 可同时停止前端和串口服务。

## 其他命令

```bash
npm run dev      # 只启动前端
npm run server   # 只启动串口服务，等价于 node server.js
npm run build    # 生产构建
npm run test:basics # 串口协议、通道锁存和答案匹配回归
```

`npm run server` 内部已经执行 `node server.js`，因此不要同时再运行
`node server.js`，否则会重复占用 8080 端口。

如果启动时出现：

```text
EADDRINUSE: address already in use :::8080
```

说明账号与串口服务已经在运行。此时不要继续重复执行 `node server.js`，
直接打开 `http://localhost:5173` 即可。需要重启时，先运行
`停止上位机.bat`，再运行 `启动上位机.bat`。

`npm start` 会先检查 5173 和 8080 端口：

- 两个服务都已运行时不会重复启动。
- 只有一个服务运行时不会继续启动，并提示先完整停止后再启动，避免把正在运行的前端意外关闭。

## 使用串口

1. 关闭 Arduino Serial Monitor 和串口助手，避免占用 COM 口。
2. 连接方式选择“本地串口服务”。
3. 选择 Seeed XIAO nRF52840 对应的 COM 端口。
4. 波特率选择 `460800`。
5. 点击“连接串口”。

前端和串口服务通过同源 `/serial-ws` 代理通信，不直接连接
`localhost:8080`，因此局域网访问时也能正常工作。

## ADC 量程

根据 `一号传感器数据0817.xlsx` 的 104 个电阻采样点，按固件公式
`V = 0.625 × 152 / (R + 0.226)` 换算：

- 电阻范围约 `56kΩ ~ 2420kΩ`。
- 电压范围约 `0.039V ~ 1.690V`。
- 1.2V 档有 16 个点超过满量程。
- 3.0V 档可以覆盖全部采样点。

因此当前基础版本固定使用 3.0V 档，避免自动切档造成的 ADC 数值跳变。
参考固件位于 `firmware/Scan16.ino`。

## 串口帧格式

固件每秒输出约 20 帧，每帧为换行结尾的字符串：

```text
rawA01,rawA02,...,rawA15\n
```

索引 `0~14` 固定对应 A01~A15，上位机不再重排。

电极分布图按电极圆点的横坐标从左到右重新排序：

```text
最左侧电极 = A01
最右侧电极 = A15
```

柱状图、校准通道和电极热点使用同一编号。该排序升级后，旧电磁排列下保存的
压力校准和触诊阈值会自动失效，需要重新执行静置清零和通道标定。

上位机还兼容带量程位图的 16 字段格式：

```text
rawA01,rawA02,...,rawA15,rangeMask\n
```

`rangeMask` 的第 `i` 位为 `1` 表示该通道使用 3V 档，为 `0`
表示使用 1.2V 档。量程位会先统一换算到 3V ADC 标尺，再进行基线扣除和
按压判断。固定 3V 固件不需要发送第 16 个字段。

## 压力校准

“15 通道压力感知可视化”页面包含逐通道压力-ADC 标定功能。

当前推荐使用“触诊阈值学习”，不需要压力测试机：

1. 连接 nRF52840 传感器串口并确认数据帧率大于 0。
2. 打开“触诊标定”。
3. 松开全部位点，点击一次“静置清零（10秒）”，采集全部15个通道的统一静态基线。
4. 点击“开始 A01～A15 顺序标定”。
5. 按好 A01，再手动点击一次“记录当前按压5秒”。
6. 系统记录全部15个通道5秒的时间加权平均值。
7. 用本次按压平均值减去A01对应的统一静置值，生成触发阈值和释放阈值。
8. 页面显示当前静置值、按压平均值和触发阈值，并询问是否重新标定。
9. 确认后进入 A02，只有按压信号需要重新采集，静置基线保持使用统一值。

算法使用统一静置清零得到的各通道静态值和“单次5秒按压平均值”，并采用回滞释放阈值减少临界抖动。页面显示每个通道最新保存的ADC阈值，阈值灵敏度可在50%～200%之间微调。

学习过程中会显示15通道实时 ADC 柱状图：

- 柱上数字始终为原始 ADC。
- 柱高固定使用 `0～10000 ADC` 标尺。
- 目标通道有独立边框，出现响应时变为红色。
- 失败时显示5秒平均ADC、静置基线、平均增量和噪声。

15个位点全部完成之前，电极压力分布图不会应用阈值高亮。全部完成后：

- 只有ADC增量达到对应位点阈值时，热点才变为红色。
- 每个实时通道柱状图显示一条红色阈值横线。
- 学习柱状图和实时柱状图均使用固定 `0～10000 ADC` 显示量程。

阈值数据保存在浏览器本地，支持导入和导出 JSON。

触诊阈值还会保存到服务主机的 `data/touch-thresholds.json`：

- 管理员可以学习、重学、导入或清除阈值。
- 普通用户和局域网其他主机只读使用同一套阈值。
- 服务主机保存失败时，页面会显示明确错误。

## 压力计换算标定

建议对每个 A01～A15 位点分别记录以下压力点：

```text
0 N、5 N、10 N、20 N、30 N、50 N、100 N、200 N
```

每个点位至少需要两个校准点才能形成有效曲线，推荐记录 0 N、中间压力和最大压力。

操作流程：

1. 连接传感器 COM 端口并确认帧率大于 0。
2. 打开“压力校准”。
3. 选择压力计 COM 端口和 `2400` 波特率并连接。
4. 选择需要校准的通道。
5. 保持传感器未受压，采集 `0 N` 点。
6. 使用压力测试机施加目标压力并保持稳定。
7. 页面会同步采集压力计读数和 ADC，并记录两者平均值。
8. 依次完成其余压力点。
9. 页面会以分段线性插值将实时 ADC 换算为压力。

当压力增大时，ADC 应保持同步增大；不符合单调关系的点会被拒绝。校准数据保存在浏览器本地，并可导入、导出 JSON 文件。

压力计串口协议参考 `Pressure-Resistance.py`：

- 波特率 `2400`。
- 打开串口后等待约 1.5 秒。
- 发送三次启动命令 `0x65`，间隔 200 ms。
- 查找 `0x55 0x01` 帧头。
- 每帧 8 字节，解析为 `0.1 N` 单位的压力值。

## 局域网访问

Vite 已经监听 `0.0.0.0`，其他主机可访问：

```text
http://<运行服务电脑的局域网IP>:5173
```

登录、HTTP API 和串口 WebSocket 都通过 5173 同源代理访问本机 8080，因此远程主机连接的是服务电脑上的串口。

Windows 防火墙需要允许 TCP `5173` 入站。当前规则名称：

```text
MPPS Web 5173 (Local Subnet)
```

规则仅允许本地子网访问，不直接向互联网开放。服务电脑切换 IP 后，应在首页查看最新的局域网访问地址。

## 登录与权限

系统启动后需要先登录：

- 普通用户可进入学习、训练、考核和传感工具。
- 管理员可额外进入信号诊断和用户管理。
- 普通用户账号由管理员在“用户管理”中创建。
- 串口 WebSocket 连接同样要求有效登录会话。

账号和训练成绩统一保存在 SQLite 数据库：

```text
data/pelvic-program.db
```

数据库包含 `users` 和 `training_results` 两张表。首次启动时，如果数据库还没有
账号，服务端会把旧 `data/auth-users.json` 自动迁移到 SQLite。训练完成后，
准确性训练、全面性训练和模拟考场成绩会自动写入数据库，管理员可在“用户管理”
页面查看最近成绩。

SQLite 使用 Node.js 内置的 `node:sqlite`，因此需要 Node.js 22.5 或更高版本。

首次初始化时，如果没有管理员账号，服务端会创建默认管理员：

```text
用户名：admin
密码：123
```

部署前建议通过环境变量覆盖默认值：

```powershell
$env:PELVIC_ADMIN_USERNAME = 'your-admin'
$env:PELVIC_ADMIN_PASSWORD = 'A-strong-password'
npm start
```

密码使用随机盐和 `scrypt` 哈希保存在 SQLite 中，登录令牌有效期为 12 小时。
`data/auth-users.json`、SQLite 数据库及 WAL 文件均已加入 `.gitignore`，不应提交到版本库。
